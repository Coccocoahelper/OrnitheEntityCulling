# Ornithe Entity Culling
This mod ports Patcher mod's entity culling feature to Ornithe, potentially improving performance, depending on the scenario.

If you're looking for entity batching, you can find it [here](https://github.com/Coccocoahelper/OrnitheEntityBatching); it was split from this mod starting from release 1.2.0, since entity batching always improves performance, but entity culling can sometimes damage it.
